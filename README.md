# 危険物甲種 学習アプリ

**危険物取扱者試験 甲種**の学習アプリです。教本・確認問題・間隔反復・模試を 1 つにまとめてあります。

**教本 50 節・確認問題 135 問**が入っています。外部通信はしません。学習記録はブラウザの中だけに残ります。

| | |
| --- | --- |
| 教本 | **50 節 / 約 140,000 字**（入門 4・法令 17・物化 13・性消 16） |
| 確認問題 | **135 問**（本番 45 問の 3 倍。法令 45 / 物化 30 / 性消 60） |
| 計算ドリル | **5 種類**（指定数量の倍数・防油堤・物質量・混合気体の全圧・熱量） |
| 体験ウィジェット | **3 個**（全 6 類の倍数・消火設備の適応表・混載表） |
| ほか | 直前チェックシート・間隔反復の復習キュー・模試（本番形式 / ハーフ / 短縮） |

**確認問題はすべて自前で書き起こしたものです。**公開問題の複製ではありません。

## 試験の形

**2026 年 9 月 15 日に[消防試験研究センター](https://www.shoubo-shiken.or.jp/kikenbutsu/)で確認した内容です。**要項は改訂されるので、受験の前に公式サイトで確かめてください。

- **五肢択一式**のマークカード方式、**45 問 / 2 時間 30 分**
- 科目は **法令 15 問 / 物理学及び化学 10 問 / 性消 20 問**
- **合格基準は、科目ごとにそれぞれ 60 % 以上。**合計点ではありません（法令 9 問 / 物化 6 問 / 性消 12 問）
- **受験資格があります。**化学系の学科等の卒業、化学の 15 単位以上の修得、乙種免状 + 実務経験 2 年以上、乙種を 4 種類以上、修士・博士のいずれか
- **科目免除はありません**（乙種と違うところ）
- 受験手数料は甲種 7,200 円
- **実施は都道府県ごと。**日程は受験する県の支部の案内で確かめてください

### 乙種第 4 類との違い

姉妹アプリに**危険物乙4 学習アプリ**（`kikenbutsu_otsu4_exam_app`）があります。**同じ試験ではありません。**

| | 乙種第 4 類 | 甲種 |
| --- | --- | --- |
| 出題数 | 35 問 / 120 分 | **45 問 / 150 分** |
| 性消 | 10 問（第 4 類のみ） | **20 問（全 6 類）** |
| 物化の科目名 | 基礎的な物理学及び基礎的な化学 | **物理学及び化学** |
| 受験資格 | なし | **あり** |
| 科目免除 | あり（他の類を受けるとき） | **なし** |
| 受験者数（令和 7 年度） | 222,545 人 | 20,296 人 |
| 合格率（令和 7 年度） | 31.9 % | 34.0 % |

### 中身の根拠

- [docs/syllabus.md](docs/syllabus.md) … **出題範囲。**甲種に公表シラバスは無いので、公開問題と法令の構造から起こしたもの。推定で埋めたところは【推定】と書いてある
- [docs/public-questions.md](docs/public-questions.md) … **公開問題 45 問が何を問うたかの分析。**原文は収録していない
- [docs/primary-numbers.md](docs/primary-numbers.md) … **数値の一次資料台帳。**法令の値は e-Gov で条文を引いて確認したもの
- [docs/section-plan.md](docs/section-plan.md) … 50 節の割り方と、章ごとの重み

**個別の物性値（引火点・発火点・比重の数値）は載せていません。**一次資料を当てられなかったためで、
本文は「水より重い」「水によく溶ける」といった**向き**で書いてあります。理由は台帳の B 節にあります。

## 方針

- **ランタイム依存は React だけ。**ルータ・Markdown・図はすべて自前
- **外部通信をしない。**学習記録は localStorage のみ。サーバもアカウントもない
- **オフラインで動く**（PWA）
- **合否は「この模試の結果が基準を満たすか」までしか出さない。**本番の合否予想はしない
- **公開問題を原文のまま収録しない。**消防試験研究センターの利用条件により、複製・二次利用は許可が要ります
