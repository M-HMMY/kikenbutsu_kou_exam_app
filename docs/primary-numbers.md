## A-3 第 4 類の品名区分（引火点）

**根拠：**別表第一 備考 十一〜十七。**引火点はすべて「一気圧において」の値です。**

| 品名 | 定義 |
| --- | --- |
| 特殊引火物 | 発火点 **100 ℃以下**、**または** 引火点 **−20 ℃以下**かつ沸点 **40 ℃以下** |
| 第 1 石油類 | 引火点 **21 ℃未満** |
| アルコール類 | 炭素原子 **1〜3 個**の飽和一価アルコール（変性アルコールを含む）。**組成等を勘案して総務省令で定めるものを除く** |
| 第 2 石油類 | 引火点 **21 ℃以上 70 ℃未満**。**塗料類その他、総務省令で定めるものを除く** |
| 第 3 石油類 | 引火点 **70 ℃以上 200 ℃未満**。**塗料類その他、総務省令で定めるものを除く** |
| 第 4 石油類 | 引火点 **200 ℃以上 250 ℃未満**。**塗料類その他、総務省令で定めるものを除く** |
| 動植物油類 | **動物の脂肉等、または植物の種子・果肉から抽出したもの**であって、引火点 **250 ℃未満**。総務省令で定めるところにより貯蔵保管されているものを除く |

> **特殊引火物の定義は「または」です。**片方だけ満たせば該当します。
> 「発火点 100 ℃以下**かつ**引火点 −20 ℃以下」と書くのは誤りです。
>
> **動植物油類は「抽出元」が定義の半分です。**引火点 250 ℃未満だけを条件にすると、
> ガソリンも当てはまってしまいます。

| **丙種**が扱える危険物 | **ガソリン、灯油、軽油、第 3 石油類（重油・潤滑油および引火点 130 ℃以上のものに限る）、第 4 石油類、動植物油類** | **規則第 49 条** |

> **★ 丙種の第 3 石油類は「全部」ではありません。****重油・潤滑油・引火点 130 ℃以上のもの**に
> 限られます。**130 ℃は規則第 49 条の括弧書きの値**です。
