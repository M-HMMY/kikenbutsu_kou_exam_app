# 体験ウィジェット

`src/components/Widget.tsx` が `import.meta.glob('./widgets/*.tsx')` で
**このフォルダの `.tsx` を自動で拾います。**登録する場所はありません。
ファイルを置けば、教本から ` ```widget:<ファイル名> ` で呼び出せます。

**★ まだ 1 つもありません。**

乙 4 版では 3 つ作りました。

| id | 何をするもの | 埋めた節 |
| --- | --- | --- |
| `baisu` | 指定数量の倍数を足し合わせる | 指定数量の節 |
| `inkaten` | 引火点・燃焼点・発火点をスライダーで行き来する | 燃焼の節 |
| `shouka` | 燃焼の 3 要素を 1 つずつ外す | 消火の節 |

**教本を書いてから作ってください。**
